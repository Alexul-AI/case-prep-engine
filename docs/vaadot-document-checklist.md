# Чек-лист документов: ведение дела נכי צה"ל
### Черновик v0.1 — дополняет «Гайд по процессу»

## Как пользоваться
Организовано по трекам и стадиям из гайда. Пункты с **[УТОЧНИТЬ]** — под реальный опыт, не только по источникам.

---

## Универсально, для любого трека
- Теудат зеut
- Первичное заявление к קצין התגמולים (форма — на сайте shikum.mod.gov.il, раздел "טפסים")
- Медицинская документация с момента самого события/начала болезни — базовая точка отсчёта для всего, что будет сравниваться дальше

## Трек A — физическая травма
- Хронологические снимки (MRI/CT/рентген) — именно последовательность по датам, а не только последний
- Заключения профильных специалистов (ортопед, невролог и т.д. — по типу травмы)
- Функциональные тесты/оценки (что человек реально может и не может делать)
- Медицинская запись с момента самого происшествия — подтверждает связь со службой

## Трек B — заболевание / психиатрический
- Заключение лечащего психиатра — регулярное, с датами визитов
- Резюме психотерапевта
- Мнение независимого эксперта (уровень профессора) — отдельная, более весомая опора
- Невролог/когнитивные тесты — если состояние того требует
- Что-то, что явно связывает симптомы со службой, а не просто фиксирует их наличие

## Для запроса ухудшения (החמרה)
- **Только новые объективные данные** — снимок, измерение, тест, показывающие изменение от базовой линии. Субъективное «стало хуже» без объективного подтверждения — недостаточно (см. паттерн отказов в гайде, п.8)
- Подтверждено официальным источником: запрос на החמרה по уже признанной травме можно подавать не раньше чем через 6 месяцев после последней комиссии по этой же травме

## Для обжалования (ערר / ערעור)
- Копия обжалуемого протокола
- Письмо-заявление в свободной форме
- Любые **новые** документы, которых не было на первой комиссии
- Подтверждение подачи (не из рук в руки — почта/расписка/email)

## На день комиссии
- Удостоверение личности
- Список документов, которые приносишь с собой (в протоколе это отдельное поле — лучше подготовить заранее, а не заполнять на месте)
- Сопровождающий — если решил, что нужен (см. отдельный документ про структуры)
- Самое важное — первым: комиссии не всегда успевают внимательно разобрать большой объём материала

## Источники
